# Lecture 4 — Fits every pocket, talks back

Exercises, playgrounds and a game for the fourth lecture. Part 1 (CSS): media
queries, fluid values, container queries. Part 2 (JavaScript): the DOM,
events and forms. All on the Harbour Night Market page.

Open `index.html` in a browser for the full list. Everything is static HTML —
serve the folder with any local server (e.g. `npx live-server`) so the live
editors and checks work.

## Start here

1. Copy `project/starter/` out of this repo into your own folder (or extract
   `project/starter.zip` there) and open that copy. Don't edit inside the repo:
   the next `git pull` would fight your changes.
2. `css/responsive.css` and `js/market.js` list today's tasks. `css/layout.css`
   is Lecture 3's layout; three of its rules need a media query.
3. Open the browser's console (F12) and keep it open while you work on the script.

Part 2 assumes you've written code before, in any language. The cheat sheet
has all the JavaScript you need.

## The market jam

`jam/index.html` explains the roles, the 30-minute clock and how to present;
`jam/01…05` are the five task briefs. Start from a copy of `project/jam/`:
today's finished page with two empty files for your group, `css/feature.css`
and `js/feature.js`.

## Playgrounds

`playgrounds/` — viewport lab (phones, the 980px lie), fluid type calculator,
DOM lab (a page, its tree and a console), event lab (bubbling, form events).
`project/showcase/` is the finished page with a switcher (keys 0–4).
`cheatsheet.html` prints on one A4 page.
